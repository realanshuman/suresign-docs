Suresign's agent can write a full agreement from a single sentence. You describe what you need, and it produces a draft with signature boxes already placed for each signer. You review it, ask for changes, and send when you are ready.

<Steps>
  <Step title="Open the agent chat">
    Open the agent from **Home**, the **Agent** page, or by pressing **A** (or **Cmd+J** / **Ctrl+J**) beside any document.
  </Step>
  <Step title="Describe the agreement">
    Type one sentence describing what you need. Include the type of document, the people or companies involved, and any key terms. If you ask for a kind of document you have a saved template for, such as "send an NDA to Dana", the agent asks whether to start from the template or write a new draft. Say "draft" to skip the question, or name the template to use it.
  </Step>
  <Step title="Watch the draft appear">
    The agent writes the agreement beside the chat in real time. It also places signature boxes for each signer and sets a signing order. When the draft is ready, a **Review and send** card appears.
  </Step>
  <Step title="Attach a file if needed">
    Click **Attach a file** to upload an existing document, purchase order, or reference file for the agent to include.
  </Step>
  <Step title="Ask for changes">
    If something is not right, type what to adjust. The agent revises the draft and shows the exact changes. Each revision appears as a new version you can accept or discard.
  </Step>
  <Step title="Check flagged addresses">
    If the agent found an email address inside a document, it flags it for you to confirm. Check it before anything is sent.
  </Step>
  <Step title="Press Review and send">
    When the draft looks right, click the **Review and send** card. This is when the document actually goes out. Nothing is sent without this click.
  </Step>
</Steps>

## What makes a good prompt

The more specific you are, the better the draft. Include the document type, the people or companies, and any important terms.

**Example prompts:**

- "Mutual NDA with Northwind Studio, two years, New York law"
- "Offer letter for Jordan Lee, software engineer, starting January 15, Rs 85,000 per month"
- "Statement of work with Alex Chen Consulting, 3 months, fixed fee of \$5,000, deliverable by March 30"

<Note>
  The agent works in the chat beside your document. Every change is shown right there, so you can see the draft evolve.
</Note>

## Reviewing signer boxes

Before you send, look at where the agent placed the signature boxes. It usually puts them at the end of the document, one section per signer. If someone needs to initial a page or fill in a date, mention that in your prompt or place those fields yourself in the editor.

## Changing a draft

You do not need to accept the first version. Type what to change and the agent updates the draft. For example:

- "Make the term one year instead of two"
- "Add a non-compete clause for six months"
- "Change the governing law to California"

Each change appears as a new version beside the chat. **Version history**, in the document's menu, keeps every past version, so you can go back if you change your mind.

## Translating an agreement

Ask for a copy in another language, for a draft the agent wrote or a document you uploaded:

- "Make a Hindi version of this"
- "Translate the NDA into Spanish"
- "Make it bilingual, English and French"

The agent makes a new draft beside the original, which stays as it is. The new draft has the same signers and signature boxes. A bilingual copy puts each clause in the original language first, then the translation, and adds a clause saying the original language prevails if the two differ.

<Warning>
  This is a machine translation, not a certified one. Have someone fluent in the language read it before anyone signs.
</Warning>

## House style and fonts

The agent writes in your workspace's house style when one is set. You can set this in **Settings**, under **Agent**. The house style covers spelling, governing law, courts, and the usual terms your workspace prefers.

You can also set any draft in one of ten fonts:

| Font | Look |
| --- | --- |
| Instrument Sans | The app's own: modern and quiet (default) |
| Inter | Clean and neutral |
| IBM Plex Sans | Corporate and technical |
| Arimo | Looks like Arial or Helvetica |
| Carlito | Looks like Calibri, Word's default |
| Tinos | Looks like Times New Roman, the classic legal look |
| Source Serif 4 | A modern serif, very readable |
| EB Garamond | Traditional and elegant |
| Libre Baskerville | Formal and bookish |
| Lora | A warm serif |

To change the font, ask the agent: "Set this draft in something like Times New Roman." The agent will pick the nearest font from the list and apply it.

<Warning>
  The agent's drafts are a starting point, not legal advice. Read every draft carefully before sending. If the document is important or complex, have a lawyer review it.
</Warning>
