You have a file that needs signatures. Upload it into Suresign, drag fields where people should fill or sign, then send. This page shows you how, field by field.

## Supported file types

Suresign accepts these files out of the box:

| File type | What to know |
| --- | --- |
| PDF | Best choice. Keeps fonts and layout exactly as you designed them. |
| Word file (DOCX) | Converts to PDF when you upload, page for page as Word lays it out. Suresign keeps page size, margins, headers, footers, fonts, lists, tables, and inline PNG or JPEG pictures. Floating pictures, text boxes, and charts are placed as close as possible, so check the preview before you send. Legacy .doc files must be saved as .docx or PDF first. |
| Image (PNG, JPG, etc.) | Converts to PDF. Make sure the text is legible. |

All uploads are scanned for viruses first. Files must be 25 MB or smaller.

<Note>
  You can also ask the agent to draft a full agreement from a sentence and place signer fields automatically. See <a href="/agent/draft-an-agreement">Draft with the agent</a>.
</Note>

## How to upload a document

<Steps>
  <Step title="Open your workspace">
    From your Suresign workspace, start a new send or open an existing draft.
  </Step>
  <Step title="Upload your file">
    Drag your PDF, Word file, or image into the upload area, or click to choose a file from your computer.
  </Step>
  <Step title="Preview the pages">
    Suresign shows you each page. Scroll through to confirm the text looks right after conversion.
  </Step>
</Steps>

If the pages look wrong, check the original file and upload again. Once the pages are clean, move on to placing fields.

## Field types you can place

After upload, you will see a toolbar of fields organized by what the signer does. Drag any field onto the page where you want it.

### Signature fields

| Field | What the signer does | Example use |
| --- | --- | --- |
| Signature | Draws, types, or uploads a signature once, then it fills every Signature field on the document | Contract signature line |
| Initials | Adds initials from the same signature ceremony | Initialing each page of an NDA |
| Stamp | Uploads or draws a company stamp or seal image | Company seal on official documents |

### Filled automatically

| Field | What happens | Example use |
| --- | --- | --- |
| Date signed | Fills automatically with the date the signer taps Finish | Signature page date line |
| Name | Fills automatically with the recipient's name as you entered it | Printed name under a signature |
| Email | Fills automatically with the recipient's email address | Contact line on a form |

### Text fields

| Field | What the signer does | Example use |
| --- | --- | --- |
| Text | Types any free text | Job title, address, notes |
| Number | Types digits only, checked as they type | Dollar amount, quantity |
| Company | Types a company or organisation name | Employer name |
| Title | Types a job title | Position on an offer letter |

### Choice fields

| Field | What the signer does | Example use |
| --- | --- | --- |
| Checkbox | Ticks a single box. Required checkboxes must be ticked before Finish | Agree to terms |
| Radio group | Picks one of several options | Select a payment method |
| Dropdown | Selects from a list you define | Choose a state or department |

### File fields

| Field | What the signer does | Example use |
| --- | --- | --- |
| Attachment | Uploads a file. It is scanned, encrypted, and listed on the certificate | Photo ID, supporting document |

That is 13 field types in total, covering signatures, dates, names, text, numbers, checkboxes, radio buttons, dropdowns, file uploads, and stamps.

## Assign fields to signers

Each field must belong to one person. Click a field and pick who it is for. Every signer only sees their own fields, and each person gets their own signing link by email.

- One signer: place all fields for that one person.
- Multiple signers: place fields for each person, such as Alex Chen signing first and Priya Shah signing second.
- You can also add approvers, people copied in, and viewers. Approvers click Approve. People copied in receive the final document. Viewers get read-only access.

You can send to up to 50 people on one document.

## Let the agent place fields for you

If you already uploaded a PDF, you can ask the agent to read it and place signature boxes and date fields in the right spots. The agent looks for signature lines, party names, and dates, then drops the fields for you. You review before anything is sent.

<Steps>
  <Step title="Open the agent chat">
    While viewing your uploaded document, open the agent chat.
  </Step>
  <Step title="Ask it to place fields">
    Say something like, "Place signature boxes for Alex and Priya, and auto-fill the date."
  </Step>
  <Step title="Review the placement">
    The agent shows you where it put each field. Move, add, or remove fields as needed.
  </Step>
  <Step title="Send when ready">
    When everything looks right, send the document. As always, the agent waits for your review before it acts.
  </Step>
</Steps>

<Tip>
  Every action the agent takes, including placing fields, is marked "with the agent" in the document's history.
</Tip>

## Tips for clean field placement

- Place fields right on the line or box where people expect to sign.
- Use "Date signed" instead of a plain Text field for dates. It fills itself and avoids mistakes.
- Use "Name" instead of a Text field for printed names. It stays consistent with the signer list.
- Leave a little space around each field so it does not overlap with nearby text.
- If a signer needs to upload a file, place an Attachment field and label it clearly.
